# 手機安全區規則（絕對不能違反）

影片在 IG Reels / TikTok / YouTube Shorts 播放時，平台 UI 會蓋住邊緣。所有元素必須避開。

---

## 平台 UI 覆蓋區域

| 區域 | 覆蓋範圍（1080x1920 直式）| 被蓋的 UI |
|------|--------------------------|-----------|
| **頂部** | y=0 到 y=180 | 狀態列 + 平台導航 + avatar |
| **底部** | y=1550 到 y=1920 | 用戶名 + 標題 + 音訊資訊 |
| **右側** | x=900 到 x=1080 | 讚 / 留言 / 分享 / 收藏按鈕 |

---

## 元素安全位置

| 元素 | 安全位置 | 原因 |
|------|---------|------|
| 頂部標題（TopicHeader）| `top: 200` | 避開頂部 UI（avatar、nav）|
| Hook 頂部文字 | `top: ≥ 200` | 同上 |
| **字幕** | **`bottom: 380`** | 在臉部下方、底部 UI 上方（不擋臉）|
| **品牌 bar** | **`bottom: 120, left: 80`** | 接受 handle/title 可能被 IG 用戶名部分覆蓋，主品牌字仍可見 |
| Hook 倒數 | `bottom: ≈ 200`（看原片字幕位置）| 避開原片可能的底部字幕 |
| **字幕寬度** | `maxWidth: 720px`, `margin: "0 auto"` | 框架置中，不用 padding（padding 不對稱會讓字幕視覺偏左）|
| 字幕對齊 | `textAlign: "center"` + `flex justifyContent: "center"` | 必須水平置中 |

---

## 原則

1. 任何文字 / 品牌元素**絕對不能**放在安全區外
2. 字幕太長時必須自動 wrap 成兩行
3. 關鍵資訊（品牌 / LINE 帳號 / CTA）**只放安全區中央**
4. 測試時想像手機平台 UI 覆蓋（用 IG Reels 實測，不要用 web preview 判斷）

---

## 用戶反饋訊號 → 對應修正

| 反饋 | 對應問題 | 修正 |
|------|---------|------|
| 「標題被 avatar 擋住」 | TopicHeader top 太小 | top: 100 → 200 |
| 「品牌 bar 被用戶名蓋掉」 | BrandBar bottom 太小 | bottom: 90 → 120 |
| 「字幕被按讚按鈕擋住」 | 字幕寬度太寬 / padding 不對 | maxWidth: 720, margin: "0 auto" |
| 「Hook 倒數被原片字幕擋」 | 倒數 bottom 太低 | bottom: 200 → 80（更貼近底部，避開原片字幕區）|
| 「字幕擋臉」 | 字幕 bottom 太大 | bottom: 550 → 380（臉下方）|
| 「字幕視覺偏左」 | padding 不對稱 | 改 maxWidth + `margin: "0 auto"` 框架置中，不用 padding |

## 字幕字級規格

| 元素 | 字級 | 顏色 | 描邊 |
|------|------|------|------|
| 普通字 | 58px | 白色 | 多層 text-shadow 超粗黑邊 |
| 高亮字 | 87px（1.5x）| 黃 / 綠 / 紅 | 多層 text-shadow 超粗黑邊 |
| 英文字幕 | 22px | 白色 85% 透明 | 細描邊 |
| 入場動畫 | spring pop 然後**靜止** | — | — |

---

## Hook 倒數區字體規格（必須夠大）

| 元素 | 字級 | 顏色 |
|------|------|------|
| 痛點提問（「你唱高音也是這樣嗎？」）| 58px 粗體 | 白色 + 粗描邊 |
| 解法預告（「只要改一個小習慣 👇」）| 46px | 金色 + 粗描邊 |
| 倒數數字（3/2/1）| 72px 粗體 | 金色 + 發光 |

**規格演進：** v1.2 是 44/36/52 用戶反饋「看不清」→ v1.3 改為 58/46/72。
