# NLP / LLM Prompt 模板

短影片文案生成的 prompt template。可用 OpenAI / Claude / 任何 LLM。

---

## API 端點（自己選一個）

### OpenAI 版
```python
import openai
client = openai.OpenAI(api_key="...")

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "你是專業的短影片文案設計師，擅長 NLP 心理學語言模式（催眠語言、前提假設、稀缺感、社群認同）"},
        {"role": "user", "content": prompt}
    ]
)
```

### Claude 版
```python
import anthropic
client = anthropic.Anthropic(api_key="...")

response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    messages=[{"role": "user", "content": prompt}]
)
```

## ① Hook 銜接文案（痛點+好奇心缺口）

### 用途
Hook 段最後的底部 copy（痛點提問 + 解法預告）。

### Prompt 模板
```
用 NLP 語言模式設計短影片的開場 Hook 文案。

場景：先播放一段[主題描述]的片段，然後轉到[領域][身份]的教學內容（教觀眾[解決方案]）。

需要在前 3-5 秒用什麼樣的文字能讓觀眾停下來繼續看？要製造好奇心和痛點共鳴。

輸出格式：
- 痛點提問一句（15 字內）
- 好奇心缺口一句（15 字內）

請產 3 組不同切角的選項。
```

### 痛點 SOP（避免踩坑）
- 直接描述影片裡正在發生的失控狀態（不是觀眾自己的痛點）
- 列舉具體失控點（例：咬字糊+音準歪+節奏亂）
- 提問結尾觸發共鳴
- 用「翻車」（用戶喜歡）但避「大咖」「真相」「教幾招」

### Hook 文案 frame 規則
- 不要 frame 主片答案（不寫主片才揭露的詞）
- 描述 Hook 影片實際失控狀態
- bigText2 不用「警報！」開頭（樣式本身已 ⚠⚠）
- 留 mystery 給主片揭露

## ② Hook 頂部新聞八卦標題（兩行設計）

### 用途
原片頂部燒字遮掉後疊新版時。

### 反例（不要這樣 prompt）
- 「設計兩行頂部標題」→ NLP 出「淚水深埋的堅毅 / 真摯詮釋如何能更自然？💭」（太文藝）
- 直接給「描述影片」→ NLP 出「機械操作？還是感情詮釋？」（問句、不像新聞）

### 正解 Prompt（必須給範本句法 + 實例）
```
用 NLP 語言模式設計短影片開場新聞風格頂部標題，兩行設計。

視覺風格參考（必須照這個句法）：
- 第一行黃底黑字 13-18 字（人物+動作+節目，如「前港姐陳凱琳登《乘風2026》」）
- 第二行白底黑字 10-15 字（動詞+具體缺點+加號或 emoji，如「唱歌遭批魔音貫耳＋overact」）

影片素材：[人物名][場景][表演項目]，被網民批評[具體 3 點]。

主片講稿核心：[痛點][真因][解法]。

關鍵字必須出現：[項目名稱]、[場景]、[主片議題]。

要讓觀眾停下來、製造好奇心。請產 4 組不同切角的選項：
1. 諷刺向
2. 共鳴向
3. 衝突向
4. 新聞八卦向（用戶偏好）
```

### 範例
- ❌ 文藝向：「《乘風2026》中的《雨愛》：淚水深埋的堅毅」
- ✅ 八卦向：「前港姐陳凱琳《乘風2026》翻車現場 / 走音＋感情斷線 解法原來很簡單!」

## ③ CTA 文案 — LINE 版

### 用途
影片結尾 CTA，引導觀眾加入官方 LINE。

### Prompt 模板
```
用 NLP 語言模式設計短影片結尾 CTA。

目的：讓觀眾加入官方 LINE 帳號 @<HANDLE>。

影片內容：[主題描述]。

CTA 需要製造稀缺感和行動動機，簡短有力，適合放在影片最後 3 秒。分成兩行顯示。

請產 3 組選項。
```

### 範例輸出
「加入官方LINE @thisissingple / 領取高音訓練秘訣」

### 三行版設計（CtaOverlay）
| 行 | 內容範本 |
|----|---------|
| line 1 | 行動指令（「加入官方LINE」）|
| line 2 | LINE 帳號（「@<HANDLE>」）|
| line 3 | 領取承諾（「[領取] [秘笈名稱]」）|

**規則：**
- line 1 / line 3 重點字染色（紅 #FF6B6B），不要全白
- LINE 版重點字：「LINE」+「秘笈名稱」
- highlights 用 `["LINE", "高音錯誤修正秘笈"]` 字串列

## ④ CTA 文案 — 留言版

### 用途
引導觀眾在影片下留言關鍵字。

### Prompt 模板
```
用 NLP 語言模式（催眠語言、前提假設、稀缺感、社群認同）設計短影片結尾 CTA。

情境：[主題]教學短影片結尾，想讓觀眾留言評論[關鍵字]，就能得到完整教材。

需要兩行：
- 第一行：行動指令（留言什麼）
- 第二行：承諾回報（得到什麼）

兩行都要短，不超過 10 字，要有畫面感和驅動力。

請提供 3 組不同風格的選項：
1. 稀缺感（限時 / 名額 / 倒數）
2. 前提假設（隱含「你需要這個」）
3. 社群認同（「跟其他人一樣得到 X」）
```

### 範例輸出
「留言「高音」 / 限時免費領取教材」（優先選稀缺感風格）

### 三行版設計（CtaOverlay）
| 行 | 內容範本 |
|----|---------|
| line 1 | 行動指令（「留言『[關鍵字]』」）|
| line 2 | 私訊承諾（「我私訊 LINE 給你」）|
| line 3 | 領取承諾（「[領取] [秘笈名稱]」）|

**規則：**
- 留言版重點字：「[關鍵字]」+「秘笈名稱」
- 兩版 line 3 統一秘笈名稱
- 兩版差異點：line 1 行動指令 + line 2 LINE 取得方式

## ⑤ 主片頂部三行標題

### 用途
教學段頂部疊三行標題（白/黃/紅）。

### Prompt 模板
```
為[主題]教學短影片設計頂部三行標題：

第一行（白色，64px）：痛點提問（觀眾正在煩惱的事）
- 必須加生活化前綴連到觀眾日常情境（KTV / 朋友面前 / 慶生 / 聚餐）
- 例：「唱歌、飆高音卡死？」（不要「飆高音脖子卡死？」太硬）

第二行（黃色，48px）：解法預告（暗示有解決方案）
- 點主片真因
- 例：「問題根本不在喉嚨」

第三行（紅色，36px）：權威背書（為什麼該聽你的）/ 後果警示（拖久了會怎樣）
- 例：「拖久了講話也回不來」/「聲樂老師不會告訴你的秘密」

整條邏輯：line 1 對齊觀眾經驗 → line 2 鎖真因 → line 3 鎖後果。
```

### 範例
- 「高音飆不上去？越用力越卡？」→「一招讓你輕鬆唱上去」→「聲樂老師不會告訴你的秘密」
- 「唱歌被說沒感情？」→「十秒解開你的束縛」→「專業訓練師的獨家心法」

## ⑥ 主片字幕 SRT 校對

### 用途
Whisper 轉錄出來的 SRT 有領域術語錯誤，用 LLM 校對。

### Prompt 模板（聲樂領域）
```
我有一份 Whisper 轉錄的 SRT，內容是聲樂教學。請校對術語錯誤。

常見聲樂專業術語：
- 副歌 / 主歌 / pre-chorus
- 起音 / 收音 / 換氣 / 共鳴
- 頭聲 / 胸聲 / 混聲
- 真聲 / 假聲 / 哨音
- 喉位 / 軟顎 / 鼻腔共鳴

校對規則：
1. 只改術語錯誤，不改內容流暢度
2. 保留原始時間戳
3. 標點符號可加可不加（保持口語感）

SRT 內容：
[paste SRT here]
```

### 替換領域（範例）
- 健身教練：squat / deadlift / hip hinge / scapular retraction / progressive overload
- 料理教學：mise en place / sear / deglaze / fold in / al dente
- 寫程式教學：variable / function / class / refactor / async

## ⑦ 高亮詞自動提取

### 用途
從 SRT 自動提取需要高亮的關鍵詞（黃/綠/紅）。

### Prompt 模板
```
我有一份[主題]教學影片的 SRT。請幫我提取需要高亮的關鍵詞。

分類規則：
- 黃色（#FFD700）：核心解法 / 技巧（例：「對的方式」「正確位置」）
- 綠色（#7FFF7F）：價值承諾 / 結果（例：「省時間」「立刻改變」）
- 紅色（#FF6B6B）：問題 / 痛點（例：「卡死」「翻車」「磨損」）

每行字幕找 0-2 個高亮詞（不要太滿）。

輸出格式：
{
  "1": [{"pattern": "卡死", "color": "#FF6B6B"}],
  "5": [{"pattern": "搞懂", "color": "#FFD700"}],
  ...
}

SRT 內容：
[paste SRT here]

額外規則：
- 同句中 substring 重疊的 patterns，**長/精準的必須排前面**（例：「錯誤位置」需在「錯位置」前）
- 物理順序直接決定 emoji 觸發順序
```

## ⑧ Emoji 配對

### 用途
為高亮詞配對 emoji（ACCENT_MAP）。

### Prompt 模板
```
我有一份[主題]教學影片的高亮詞列表。請按情緒分類配 emoji。

分類：
- negative（描述問題/錯誤）→ ⚠️ 😰 ❌ 💢
- positive (KEY revelation) → ✨ 💡 ⭐ 🎉
- bridge (CTA hint) → 🎯 👇 📢 ⏰

規則：
- 比例 ~18%（5 emoji on 28 lines），不要太滿
- 每支影片 5-8 個 emoji 點

高亮詞列表：
[paste list here]
```
